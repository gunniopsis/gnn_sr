# Recreate report outputs

Run these commands locally after retrieving the completed runs and installing `.[plot]`. Keep the directory layout in this repository. Commands verify available provenance and generate fresh artifacts under `outputs/` or `reports/`; neither generated directory is committed.

## AOI results (Appendix B)

```bash
python scripts/compare_hidden_widths.py
python scripts/report_loss_experiments.py --stage all
python scripts/plot_loss_heatmaps.py --stage all
python scripts/plot_depth_heatmaps.py
python scripts/plot_report_aoi.py
```

The first four commands validate runs and prepare comparison summaries. The final command uses those summaries to reproduce the report's width comparison (Figure 20), full temperature/weight grid (Figure 21) and message-passing grid (Figure 22), with orange outlines marking the report's adopted settings. It writes to `reports/figures/aoi_tuning/`. Width summary CSVs supply Table 8. The loss reporting must precede its heatmaps. The `--stage all` option includes the two later temperatures. Incomplete runs/evaluations must be completed before treating the grid as final.

## Training history (Appendix C)

```bash
python scripts/plot_report_training.py
```

Creates the Figure 23 training panels and `epoch_metrics.csv` for Table 9 in `reports/figures/training/`. Selection is recomputed from the history. The figure contains training/validation loss, weighted extent loss, depth RMSE, timestep CSI, learning rate and runtime. A run that stops early has fewer than 100 table rows.

## Main comparison and Appendix D

After full-domain inference and common-mask comparison:

```bash
python scripts/plot_full_domain_final_boxplots.py
```

This generates Figure 8 from the 18-event LF/GNN-SR/LSG metric table. After saved-LSG inference has also completed:

```bash
python scripts/tabulate_full_domain_evaluation.py
python scripts/export_inundation_area_timeseries.py
python scripts/tabulate_inundation_area_timing.py
```

These produce the per-event metric tables (Tables 10-14) and maximum-total-inundation-area timing table (Table 15). The table exporter consumes the boxplot metadata, so run the boxplot command first. Measured GNN timing is in the full-domain `test_event_metrics.csv`; LSG timing is in its `event_metrics.csv`. Hydraulic runtimes in Tables 7/16 originate from external simulation records and cannot be regenerated by executing the neural network. Compare hardware and timing boundaries explicitly; do not replace hydraulic simulation runtimes with file-read/export times.

## Event 16: spatial exports and distributions

The default event is `e1971_real_slmax_1in100`. Run:

```bash
python scripts/export_maximum_extent_gis.py
python scripts/export_maximum_depth_gis.py
python scripts/export_maximum_depth_error_gis.py
python scripts/export_maximum_depth_error_gis.py --signed
python scripts/export_extent_classification_change.py
python scripts/plot_wet_union_depth_differences.py
```

The GIS commands export the underlying georeferenced rasters for Figures 9-11, 13 and 15. The wet-union script produces the signed-depth histogram and five-class distribution for Figures 14 and 16. It preserves the common scoring mask and excludes cells dry in all three models throughout the event. Rasters are in EPSG:28356; use QGIS for map framing, basemaps, legends and page composition. The original QGIS print layouts and third-party basemap tiles are not part of this source package, so map presentation may differ while the numeric raster content is reproducible.

## Event 16: hourly behaviour

```bash
python scripts/plot_temporal_extent_metrics.py
python scripts/plot_temporal_depth_rmse_volume.py
```

These regenerate hourly CSI/POD/RFA (Figure 12) and depth RMSE/volume (Figure 17). They read full timestep predictions, not just peak maps. Preserve the event times and global cell identifiers. The depth/volume script uses the fixed wet-union support described in the report.

The model schematics and study-area illustrations explain the method rather than represent additional experiments. The supplied AOI/full-domain polygons and the source graph code define their computational geometry.
